Arrays Package

The SparForte built-in arrays package provides subprograms to work with array variables and array types. This includes finding the size of the array and reordering the components in the array.

GCC Ada Equivalent: array attributes, GNAT sort packages

  first( a )               last( a )                    length( a )
  bubble_sort( a )         bubble_sort_descending( a )
  heap_sort( a )           heap_sort_descending( a )
  shuffle( a )             flip( a )
  shift_left( a )          shift_right( a )
  rotate_left( a )         rotate_right( a )
  to_array( a, s )         to_json( s, a )
 
Help Command: Contents of the arrays package

arrays.bubble_sort( a )

 

Sort the array using the bubble method, treating the components as strings or numbers depending on the component type.

Example

 arrays.bubble_sort( sales_array );

Parameters
Param Mode Type Default Meta Tags Description
a in out any array type required no meta tags checked the array to sort

Exceptions

The array components must have assigned values
The array must not be too large
The array element types must be sortable (string, numeric or enumerated)
The system does not run out of memory
The components must be writable

See Also

arrays.bubble_sort_descending
arrays.heap_sort
arrays.heap_sort_descending

Compare With

Ada: GNAT.Bubble_Sort
PHP: sort

arrays.flip( a )

 

Reverse the order of the components in the array. The procedure moves the last component to the first position and the first component to the last position. (The name was changed in version 1.1. The name was originally arrays.reverse. This conflicted with the Ada reserved word "reverse".)

Example

 arrays.flip( backwards_array );

Parameters
Param Mode Type Default Meta Tags Description
a in out any array type required no meta tags checked the array to reverse

Exceptions

The array components must have assigned values
The components must be writable

See Also

-

Compare With

Ada: N/A
PHP: array_reverse

arrays.to_array( a, s )

 

Decode a JavaScript Object Notation (JSON) formatted string, storing the values in the array.

Example

 s := "[32]";
arrays.to_array( a, s ); -- a(1) is 32

Parameters
Param Mode Type Default Meta Tags Description
a out an array type required no meta tags returned the array to assign values to
s in json_string required meta tag checked against authorized tags the JSON expression

Exceptions

For more details and exceptions, see the Reference Manual section JSON and SparForte Types.
