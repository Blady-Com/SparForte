Arrays

Arrays are composite types that contain lists of components. The values of the components are a single type.

You access individual values an index. The index uses a numeric or an enumerated type.

Arrays have a fixed size. The index range determines the size. The array type declaration sets lower and upper bounds of the array. Anonymous arrays, which do not have a type, set the bounds when the array is declared. It is an error to access elements outside of the index's range.

The built-in arrays package contains basic array subprograms.

Anonymous Arrays

To declare an anonymous array (an array with no type name):

=> zebra_population : array(1900..2009) of natural
=> type divisions is (america, asia, africa, europe, oceania )
=> sales : array (america..oceania) of float

The first array contains 100 components. Each component is a natural number.  To access array entries, use the index in parentheses after the array name.

=> zebra_population(1950) := 150000
=> ? zebra_population( 1950 )
150000

Attempting to use an out-of-range index number is an error.

=> ? zebra_population( 0 )
   ^ exception raised

Array Types

You can create new array types.

=> type zebra_list is array( 1900..2009 ) of natural;
=> zl : zebra_list

Initial Values

When you declare an array, initial values are optional. You can supply initial values or copy the values of another array of the same type. Supply initial values for every component.

=> type grocery_list is array(1..10) of string

=> gl : grocery_list := ( "milk", "bananas", "bread", "butter", "salt", "flour", "pizza", "noodles",  "", "" )
=> gl2 : grocery_list := gl
=> ? gl2(2)
bananas

Empty Arrays

An empty array is created using an index of 1..0 or any range where the first bound is greater than the second bound.

=> empty : array(1..0) of integer

SparForte does not copy one array to another in an assignment statement. It does not support unconstrained arrays or multi-dimensional arrays.

Ada: SparForte does not (yet) implement arrays with multiple dimensions (arrays of arrays) or arrays with records. Character and indefinite indexes are not implemented. The others keyword is not yet available for assignment.
