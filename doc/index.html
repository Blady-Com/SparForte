Welcome to SparForte

This is the official documentation for SparForte (that is, this is the SparForte manual). SparForte developers and volunteers have contributed to this manual.

It contains several sections: tutorials, a language reference, the design rationale and introductory material. Start by selecting a section name from the top menu. The summary below describes each section.

The side menu lists topics for each section.

The SparForte home page is http://www.pegasoft.ca/sparforte.html.
