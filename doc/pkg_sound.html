Sound Package

The SparForte sound package plays music and sounds and controls the sound hardware on the computer. The package uses the gstreamer library.

  play( f [, p] )
  playcd [( f )]
  stopcd
 
Help Command: Contents of the sound package

sound.play( f [, p] )

 

Play a sound file using the gstreamer library. The priority is ignored.

Example

 sound.play( "waterfall.wav" );

Parameters
Param Mode Type Default Description
f in universal_string required the sound file to play
p in integer highest integer ignored.
Obsolete: will be removed

Implementation Note

This procedure originally used Warren Gay's AdaVOX library but now uses gstreamer.

sound.playcd [( f )]

 

Play an audio CD in /dev/cdrom (or an alternative CD device if specified).

Example

 sound.playcd;

Parameters
Param Mode Type Default Description
f in universal_string /dev/cdrom the name of the CD device
